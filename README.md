# AI_tools

Personal tooling used with AI agents.

- `uni_vault/`: scripts for the Obsidian university vault (lecture watcher, transcription, AI notes, Anki, name checks). `uni_vault/vault` is a link to the vault in Google Drive; the scripts work on the notes through it.
- `spellcheck_pt/`: offline European Portuguese spellchecker and PT-BR filter.

## Setup
```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
```
In PyCharm, set the interpreter to `AI_tools/.venv/bin/python`.
